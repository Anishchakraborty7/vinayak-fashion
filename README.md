# 👑 VINAYAK FASHION — Tradition, Reimagined
> **A High-End Indian Luxury Fashion Web Experience**  
> Blending millenia-old Indian textile heritage with modern editorial design, 3D interactive web experiences, and seamless responsiveness.

---

## 🌟 Key Highlights & Architecture

### 1. ⚜️ Visual Design & Royal Color Palette
- **Warm Indian Luxury Palette**: Royal Burgundy (`#440D17`), Deep Crimson (`#7A1C28`), Midnight Charcoal (`#0D080A`), Metallic Antique Gold (`#D4AF37`), Ivory, and Warm Cream.
- **Editorial Typography**: Pairing classical serif headings (`Playfair Display`, `Cinzel`) with geometric sans (`Plus Jakarta Sans`).
- **Authentic Indian Motifs**: Subtle sacred lotus, kalash, jaal, and intricate gold borders.

### 2. 💎 3D Web Experiences (Three.js)
- **Hero 3D Medallion**: Interactive 3D jewelry ornament featuring concentric rotating gold rings, embedded ruby gemstones, and floating golden light particles responding to cursor movement.
- **Craft 3D Kinetic Sculpture**: Interactive 3D geometric handloom visualization representing the sacred warp & weft weave.

### 3. 🛍️ Interactive Luxury Components
- **Navbar**: Full responsive luxury bar with vector SVG logo, smooth anchor navigation, search trigger, wishlist indicator, and shopping bag.
- **Infinite Marquee**: Golden divider ticker highlighting hallmark artisanal qualities.
- **Curated Category Showcase**: Women's Royal Couture, Men's Imperial Regalia, and Artisanal Heirlooms with rich hover-depth transitions.
- **3D Perspective Product Slider**: Dynamic horizontal card carousel with realistic 3D tilt tracking.
- **Interactive Product Modal**: Complete quick-view modal with multi-angle gallery, bespoke hue swatches, fabric/karigar provenance specs, and pre-order reservation flow.
- **Live Search Overlay**: Instant search and filtering across products, fabrics, and categories with keyboard shortcuts.
- **VIP Newsletter**: Golden confetti celebration (`canvas-confetti`) upon joining the inner circle.
- **Responsive Mobile Menu**: Full-screen slide-in mobile navigation drawer with touch-friendly navigation and contact details.

## 🚀 Getting Started

### Development
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```

### Code Quality & Linting
```bash
npm run lint
```
*(Zero lint warnings and zero errors across the entire codebase)*
